# NostrDevs San Salvador

A [website](https://nostrdevelsalvador.org/) for the Nostr developers community in San Salvador. 
Creating a space to share knowledge, experiences, and projects.
We organize monthly events which you can find [here](https://www.eventbrite.co/e/nostr-dev-reunion-el-salvador-aprender-y-conocer-y-desarrollar-tickets-962480684637?utm-campaign=social&utm-content=attendeeshare&utm-medium=discovery&utm-term=listing&utm-source=cp&aff=ebdsshcopyurl).

## Technologies

This project is developed in [Rust]() and built with the following technologies:

- [HTMX](https://htmx.org/docs/) - for frontend interactivity
- [Axum](https://github.com/tokio-rs/axum) - as an HTML server
- [Tailwind CSS](https://tailwindcss.com/) - for styling

## Contributing

If you want to contribute to this project, please follow these steps:

- If you want to suggest a discussion topic, you can open an [issue](https://github.com/illuminodes/nostr-devs/issues/new)
- If you wish to contribute with code, you can [fork](https://github.com/illuminodes/nostr-devs/fork) this repository and send a [pull request](https://github.com/illuminodes/nostr-devs/pulls)
